개인정보처리방침

시행일: 2026년 11월 19일

1. 이 앱은 무엇인가요

movie-shorts는 유튜브 채널 운영자가 본인 채널에 영상을 업로드하고 본인 채널의 통계를 확인하기 위한 개인용 도구입니다. 일반 사용자에게 제공되지 않습니다.

2. 사용하는 Google 데이터

  • YouTube 업로드·관리 권한: 운영자 본인 채널에 영상을 올리고 관리합니다.
  • YouTube 읽기·분석 읽기 권한: 운영자 본인 채널의 영상 목록과 조회수를 확인합니다.

3. 수집·저장·공유

이 앱은 운영자 외 다른 사람의 개인정보를 수집하지 않습니다. Google 로그인 토큰은 운영자의 컴퓨터에만 저장되며, 어떤 서버로도 전송하거나 제3자와 공유하지 않습니다. Google 사용자 데이터를 광고, 판매, AI 모델 학습에 사용하지 않습니다.

4. 권한 해제

Google 계정의 서드파티 앱 및 서비스에서 언제든지 이 앱의 접근 권한을 해제할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책

이 앱이 Google API에서 받은 정보를 사용하는 방식은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

6. 문의
